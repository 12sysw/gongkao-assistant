# 公考 AI 教学技能

`src/main/ipc/gongkao-skill.ts` 是 AI 问答与申论批改共享的教学约束层。

## 覆盖范围

- 单题讲解：题型识别、思路、过程、答案、易错点与同类迁移。
- 行测方法：资料分析和数量关系必须呈现关键公式或速算依据；言语、判断和常识说明判断或排除依据。
- 申论批改：给出审题、要点、语言、格式和可执行修改；大作文只给结构与论据方向，不代写完整范文。
- 备考计划：缺少目标考试、时间、水平或薄弱项时，先声明假设并提示补充信息。
- 时效信息：对政策、公告、时政、真题年份明确资料日期和不确定性。

## 维护原则

- 通用规则只放在 `gongkao-skill.ts`，避免聊天与申论批改提示词分叉。
- 知识库资料是可引用事实的唯一来源；资料缺失时应明确说明。
- 新增题型时，补充可验证的输出规则，而不是只追加角色描述。
