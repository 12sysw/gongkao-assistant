# 公考小助手 v3.0.1

面向 Windows 的本地优先公考学习桌面端。当前版本已完成核心化精简，侧栏只保留高频学习流程，错题、PDF 导入、答题纸和能力树收进对应核心页面，避免功能堆叠和新版/旧版页面长期并存。

## 核心入口

侧栏固定保留 8 个入口：

1. **首页**：显示今日待办、复习数量、连续学习状态和备考追踪入口。
2. **今日复习**：统一处理到期记忆卡片与错题复盘；错题本作为二级入口保留。
3. **套题模考**：正式考试计时、挑战模式、答题报告和 AI 薄弱项分析。
4. **真题题库**：管理结构化题目；可进入“已导入真题”和“PDF 真题导入工作台”。
5. **申论训练**：OCR 录入、AI 批改、建议/实际用时和改写建议；可生成申论答题纸。
6. **AI 名师**：RAG 知识库与花生十三题型化教学模式。
7. **备考追踪**：记录训练、生成总结、复盘错题；能力树作为二级入口保留。
8. **设置**：AI 模型、数据备份、应用更新和主题配置。

## 核心工作流

### 真题导入

1. 进入 **真题题库 → PDF 真题导入**。
2. 文本型 PDF 优先解析，扫描件可使用 OCR。
3. 在标准试卷预览中校对题号、题型、题干、选项和答案。
4. 确认后同步到题库，并可用于套题模考。

### 今日复习与错题闭环

- 到期记忆卡片和错题统一进入“今日复习”。
- 错题支持标准解析、个人错因和下次复习提醒。
- 首页优先展示今天需要完成的任务，而不是堆叠低价值统计模块。

### 申论纸笔训练

- 上传题目与答案图片后使用 OCR 识别并人工校正。
- 批改结果记录本题建议用时、实际用时与改写建议。
- 按题数、字数和建议用时生成可打印 PDF 或 PNG 答题纸。

### AI 名师

内置以下模式：

- 花生十三·自动识别
- 行测速解
- 基础讲解
- 申论审题
- 错因复盘
- 备考规划
- 通用 RAG

行测模式强调题型识别、关键步骤、速算技巧和易错点；申论模式提供审题框架与修改建议，不代写完整答案。

### 备考追踪与能力树

- 桌面端只暴露状态、训练记录、总结和复盘 4 个核心动作。
- 能力树吸收 `human-skill-tree` 的能力节点思路。
- 备考追踪保留 `kaogong-study-tracker` 的上游快照，并通过校验脚本保证源码、构建产物和安装包内容一致。

## 已移除的非核心桌面功能

以下页面和专用前端依赖已删除：番茄钟、成就页、聊天室、鼓励语录、思维导图、知识图谱、独立学习计划页、独立记忆卡片页、打卡倒计时、残酷报告、组件展示页以及重复的新旧版壳页面。

旧数据库表和部分历史 IPC 暂时保留，仅用于旧数据兼容和迁移；它们不再提供独立桌面入口。

## 数据与隐私

主要学习数据保存在本机：

```text
C:\Users\<用户名>\AppData\Roaming\gongkao-assistant\
├── gongkao.db
├── ai_config.json
└── rag_config.json
```

`kaogong-study-tracker` 数据默认位于：

```text
C:\Users\<用户名>\.kaogong-study-tracker\data\
```

建议定期在设置页导出完整 JSON 备份。AI 请求会发送到用户自行配置的 OpenAI 兼容接口，请根据所选服务商的隐私政策决定是否上传敏感材料。

## 安装与更新

- NSIS 安装版支持应用内检查更新。
- 便携版可直接运行，不写入安装目录。
- 当前仅构建 Windows x64 版本。

## 开发

```bash
npm install
npm run electron:dev
```

| 命令 | 作用 |
| --- | --- |
| `npm run lint` | 执行渲染进程与主进程 TypeScript 严格检查 |
| `npm run test` | 构建主进程并运行 IPC/核心功能防回退测试 |
| `npm run build:all` | 构建渲染进程与 Electron 主进程 |
| `npm run electron:build` | 生成 Windows 安装版和便携版 |
| `npm run verify:study-tracker` | 校验上游备考追踪 Skill 快照 |
| `npm run verify:study-tracker:package` | 校验打包后的 Skill 文件 |

## 技术栈

- Electron 33

- Vite 6 + Tailwind CSS 3
- better-sqlite3 + Drizzle ORM

- OpenAI 兼容接口与本地 RAG
