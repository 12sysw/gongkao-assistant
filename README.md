# 公考小助手 v2.1

桌面端公务员考试学习工具，基于 Electron、React、TypeScript 和本地 SQLite 构建，集刷题、错题整理、记忆巩固、AI 辅导和复习节奏管理于一体。

## 主要功能

- **仪表盘**：学习概览、天气信息、每日语录、智能推荐、学习统计导出
- **题库管理**：题目导入、分类、OCR 图片识别
- **错题本**：错题收集、分类、统一复习、**导出为 Excel/PDF**
- **记忆卡片**：间隔重复算法，科学记忆、**导出为 Excel/PDF**
- **知识图谱**：LLM 驱动的知识点提取与可视化（力导向布局、缩放平移、搜索高亮）
- **知识库**：RAG 向量检索，智能问答
- **申论 AI 批改**：流式反馈，逐段点评
- **套题测评**：模拟真实考试，AI 分析薄弱环节
- **思维导图**：知识点可视化整理
- **学习计划**：目标管理与进度追踪、法定假日标记、**导出为 Excel/PDF**
- **番茄钟**：专注学习计时、桌面通知提醒
- **打卡系统**：连续学习天数统计
- **聊天室**：多人在线交流，支持文字/图片/文件
- **鼓励语录**：随机语录、答案之书，备考激励
- **深色模式**：一键切换深色/浅色主题，侧边栏底部切换
- **自动更新**：启动检测 + 定时检查（每4小时），后台下载，一键安装

## 安装使用

1. 从 [GitHub Releases](https://github.com/12sysw/gongkao-assistant/releases) 下载最新安装包
   - `gongkao-assistant-Setup-x.x.x.exe` — NSIS 安装版（推荐，支持自动更新）
   - `gongkao-assistant-x.x.x.exe` — 便携版（免安装，直接运行）
2. 双击运行安装程序，选择安装目录
3. 启动应用，进入**设置**页面配置 AI 接口（可选）
4. 导入题库即可开始刷题

## 使用指南

### 仪表盘

进入应用后的首页，展示：
- 学习进度概览（连续天数、总题目数、学习时长）
- 天气信息（默认北京，可在设置中修改）
- 今日建议（根据待复习内容自动推荐）
- 学习统计卡片（可导出 Excel/PDF）

### 题库管理

1. 点击左侧菜单**题库管理**
2. 支持 PDF 导入：设置页面配置题库目录路径，自动扫描子目录中的 PDF 文件
3. 支持手动添加题目，选择题型（言语理解、数量关系、判断推理、资料分析、常识判断、申论）
4. 支持 OCR 图片识别：粘贴截图自动识别题目文字

### 错题本

- 做题过程中自动收集错题
- 支持按题型筛选、按掌握状态筛选
- 点击题目可查看详细解析
- **导出功能**：点击顶部**导出**按钮，选择 Excel 或 PDF 格式

### 记忆卡片

- 基于间隔重复算法（类似 Anki），科学安排复习时间
- 支持按分类筛选（常识-政治/法律/经济/人文/科技、行测-公式、申论-金句）
- 三种模式：全部 / 待复习 / 已掌握
- **导出功能**：点击顶部**导出**按钮，选择 Excel 或 PDF 格式

### 知识图谱

- AI 自动从题库中提取知识点，构建知识网络
- 力导向布局，支持缩放、平移
- 点击节点查看关联题目和描述
- 搜索功能快速定位知识点

### 知识库（RAG 问答）

1. 进入**智能问答**页面
2. 先在设置中配置 AI 接口（API 地址、Key、模型名称）
3. 可导入 PDF 文档构建知识库
4. 输入问题，AI 基于知识库回答

### 申论 AI 批改

1. 进入**申论批改**页面
2. 选择题型（概括归纳、综合分析、提出对策、贯彻执行、大作文）
3. 粘贴题目和你的作答
4. AI 逐段点评，给出修改建议

### 套题测评

1. 进入**模拟考试**页面
2. 选择套题开始答题，限时 120 分钟
3. 答完后 AI 自动分析薄弱环节
4. 查看各题型正确率和用时统计

### 思维导图

- 自由创建，选择科目分类
- 支持节点增删改、拖拽调整
- 适合梳理考点脉络和知识体系

### 学习计划

- 创建学习目标，设置每日学习时长
- 支持优先级（高/中/低）和状态（待开始/进行中/已完成）
- 30天学习热力图，可视化打卡记录
- **导出功能**：点击顶部**导出**按钮，选择 Excel 或 PDF 格式

### 番茄钟

- 25 分钟专注 + 5 分钟休息
- 每 4 个番茄后长休息
- 记录每日番茄数和专注时长

### 打卡系统

- 每日自动记录学习数据
- 连续学习天数统计
- 法定假日标记（不影响连续天数）

### 聊天室

- 多人在线交流，支持文字、图片、文件
- 基于腾讯云 IM
- 首次使用需登录/注册账号

### 深色模式

- 侧边栏底部点击**深色模式**按钮一键切换
- 设置自动保存到本地
- 所有页面和组件均已适配

### 数据导出

以下页面支持导出为 Excel（.xlsx）或 PDF 格式：

| 页面 | 导出内容 |
|------|----------|
| 错题本 | 题目、答案、解析、复习次数、掌握状态 |
| 记忆卡片 | 正面、背面、分类、复习次数、下次复习时间 |
| 学习计划 | 标题、科目、优先级、状态、每日时长 |
| 仪表盘 | 学习统计（日期、学习时长、做题数量、错题数量） |

### 设置页面

- **AI 接口配置**：API 地址、API Key、模型名称（用于知识图谱、申论批改、套题测评等 AI 功能）
- **题库目录**：PDF 题库文件的根目录路径
- **数据备份**：完整导出/导入所有数据（JSON 格式）
- **关于**：查看应用版本、检查更新

## 数据存储

所有数据保存在本地，不会上传到服务器：

```
C:\Users\<用户名>\AppData\Roaming\gongkao-assistant\
├── gongkao.db          # 主数据库（SQLite）
├── ai_config.json      # AI 接口配置
└── rag_config.json     # RAG 知识库配置
```

**备份建议**：定期在设置页面使用**数据导出**功能，保存 JSON 备份文件。

## 自动更新

- 安装版（Setup）支持自动更新
- 启动时自动检查新版本
- 后台下载更新包，下次启动自动安装
- 也可在设置页面手动检查更新

## 开发

```bash
npm install
npm run electron:dev
```

| 命令 | 作用 |
|------|------|
| `npm run electron:dev` | 开发模式运行 |
| `npm run build` | 构建渲染进程 |
| `npm run build:main` | 构建主进程 |
| `npm run build:all` | 构建主进程和渲染进程 |
| `npm run electron:build` | 生成 Windows 安装包和便携版 |
| `npm run lint` | TypeScript 校验 |
| `npm run test` | IPC 契约测试 |

## 常见问题

**Q: AI 功能不工作？**
A: 请在设置页面配置 AI 接口。支持任何 OpenAI 兼容的 API（如 DeepSeek、智谱 GLM、通义千问等）。

**Q: 数据可以迁移到另一台电脑吗？**
A: 可以。在设置页面点击**数据导出**保存 JSON 文件，在新电脑上使用**数据导入**恢复。

**Q: 支持 macOS/Linux 吗？**
A: 目前仅支持 Windows。macOS 和 Linux 支持已列入开发计划。

**Q: 如何备份学习数据？**
A: 设置页面 → 数据导出，会生成完整的 JSON 备份文件。
